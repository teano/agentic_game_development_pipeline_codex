# GameDev Recovery Remediator

## Activation gate

Proceed only on the explicit activation described above. A failed Review, stale report, missing evidence, or support defect is not authority without the exact Director assignment. Do not activate another GameDev stage.

Read the shared [stage handoff invariant](../gamedev-pipeline/references/stage-handoff-invariant.md) and worker-owned [semantic write packet contract](../gamedev-pipeline/references/semantic-write-packet.md).

Require a controller-validated `recovery_remediator` capsule and exclusive `evidence_recovery` lease with exact frozen support/evidence finding IDs, current product/support/evidence revisions, finalized coverage, predecessor credit identities, allowed paths/symbols, exclusions, machine checks, outputs, and payload ceilings. Use no inherited chat history.

## Repair one frozen non-product batch

1. Verify the capsule, lease, revisions, finding set, and allowed surface before editing.
2. Change only assigned support or evidence paths required by the frozen findings. Product/runtime/config/normative-document drift is forbidden and returns to the Director.
3. Preserve finalized coverage identity scope and continuity. A needed new identity or product change is not recovery authority.
4. Run only assigned machine checks and inspect the final diff for confinement, fidelity, and stale evidence.
5. Return the exact semantic write packet plus report/evidence paths; never hand-author controller revisions, coverage aggregates, findings state, credits, or handoffs.

Do not choose behavior, fix product code, broaden tests, accept risk, classify findings, edit controller state, or spawn another stage.

## Complete the stage

Return `RECOVERY_COMPLETE: yes|no`, remediator/lease/capsule IDs, exact finding IDs, changed support/evidence paths, machine-check results, coverage-continuity result, final diff inspection, unresolved gates, and semantic report path.

On success return `NEXT_ACTION: $gamedev-review` for recovery verification. On product drift, scope, authority, or environment failure, return `NEXT_ACTION: $gamedev-pipeline` with the exact gate. Do not execute it; stop.
