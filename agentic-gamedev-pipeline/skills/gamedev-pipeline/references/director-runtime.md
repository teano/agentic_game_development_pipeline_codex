# Director event router

Load linked sections only for their named event; do not preload rare routes or role manuals. Native controller owns transitions/validation; specialists own semantics/source selection. Preserve actual permissions, approval actors and SKILL prohibitions.

## Read instructions without clipping

Use the [instruction/source reader](delivery-contract.md#read-without-loss) with the selected launcher and exact root/feature even before initialization. `file-read --instruction director --path references/director-runtime.md --section "Ordinary event map" --format text --assemble` reads this route; returned `linked_reads` supplies exact handles for its required canonical sections. Use [Host command presentation](delivery-contract.md#host-command-presentation) to retain the full command/session result and emit decoded selected output. Consume required text fully and retain unchanged policy; clipping uses the existing recovery route. The recipient reads semantic sources and its own role instructions.

## Binding and delivery

`P` is the supplied `launcher_argv` plus exact `--root <root> --feature <slug> --brief`, retained as separate argv elements. `A` is the latest delivered complete native `next_action`. `S(A)` means `P step --expected-generation <A.expected_generation> --action-id <A.command_id> --through-handoff`. Retain original requests for replay; native assignment/generation/action IDs are never invented.

Keep root/runtime/permission locators, native cursor, physical owner/role/model/alias/assignment/output/lifecycle, grant/baseline/handles, actual return route, current/just-completed binding, consumed sequence/fingerprint and one pending request with its reconciliation allowance in the existing checkpoint. Semantic results/decisions remain in native artifacts. Retain a command's complete host envelope and original request, including any running inner handle; collect terminal stdout before parsing. Empty output or outer completion does not establish inner completion. The event map and conditional transport route govern continuation.

First dispatch reads shared [ownership](stage-handoff-invariant.md#one-owner-and-one-current-assignment), [caller binding/template](control-return.md#caller-binding-and-dispatch) and [event consumption](control-return.md#consume-worker-events). Read [technical role responsibilities](technical-decisions.md#role-responsibilities) only when current decisions or a technical event apply. Specialists select relevant full entries. New authorized owner: `spawn_agent`, `fork_turns:"none"`, with the applicable [model/effort](agent-model-policy.md#delegated-roles) or actual override. Reuse eligible same-slice owners; an accepted behavioral boundary follows the source-bound [physical-context handoff](stage-handoff-invariant.md#working-set-checkpoint-and-rotation). Engineering/Review/QA stay independent.

Forward delivery/`role_instructions` unchanged using `assignment_delivery.dispatch`, adding only the actual host binding, permissions/check grant and return route from the caller contract. The recipient runs its generated complete readers. The descriptor supplies scope/output and invocation syntax, not controller command authority. The exact issued terminal output is already authorized separately from product writes, including read-only roles; actual tool/filesystem denials follow their factual route. The specialist resolves tools/resources from stable locators in its own session; session-local handles do not transfer.

Deliver full current input unless this continuing owner has an eligible retained baseline under [Update the same worker](delivery-contract.md#update-the-same-worker). Fresh/replaced/lost-context owners need full content. Missing delivery or a same-owner delta after an unconditionally full handoff uses the conditional export route; do not re-export just for identity. Baseline acknowledgment rides the next necessary event, never a ping.

## Wait for agent events

Apply [Await a bound response](control-return.md#await-a-bound-response) to Directors and every delegated role. Consume an actual event immediately through its routing row; a host timeout alone creates no routing work. Preserve the one pending request and same owner when a host pause is needed.

## Ordinary event map

Filter duplicates first. Native guards remain binding; tool success, prose or files prove neither PASS nor liveness.

| Event / preconditions | Only allowed action; artifact recipient and boundary |
| --- | --- |
| Entry/restore; known root/authority | One `P status` and known-owner/handle observation only as restoration requires. No runtime: ingress index without status. Unknown ownership forbids duplicate dispatch/mutation. |
| `A.command=next` or `accept`; no live mutation/grant/unconsumed result | `S(A)`. Use returned typed outcome, final cursor and delivery; dispatch the first new assignment. Stop the chain at question/failure/recovery/ready. |
| Native assignment issued; permissions/capacity/current identity available | Match native role AND current slice against the consumed transition. Same-slice remediation reuses its owner; a newly accepted behavioral boundary selects a fresh Engineer unless the exact prebound continuity instruction applies. This also applies when `--through-handoff` returns the new assignment in one response. Preserve native identity, prior quiescence and no active grant; dispatch its full current input to a new physical owner. Idle eligible owner: `followup_task`; new owner: `spawn_agent`. Wait for an event; no manual preload or replacement merely for a new assignment ID. |
| Bound terminal notice while owner still runs | Retain exact notice/output; wait for actual host termination and account for owned processes/editor activity. No `complete`, format repair or second dispatch. |
| Genuine terminal event; actual termination, quiescence and exact assignment/output; `A.command=complete` | If retained complete `A` is current, immediately `S(A)`, including fail/blocked output: **no preceding status**. A partial final wrapper does not invalidate an unchanged retained `A`. If a native check/external mutation advanced the cursor and the new full `A` was not delivered, one `P status` restores it, then `S(A)`. Never infer a changed action ID from generation. |
| Native `phase_failed`/`gate_failed` | Use returned `A` and its row. An unchanged failed attempt may return `no_progress_resolution_required`; use its conditional route. Controller selects remediation owner and carries complete findings/failure evidence. Keep that owner; no Director semantic judgment, self-selected role or old Review/QA PASS. |
| Informative native `check_result`; same assignment/caller grant active and owner live | Retain its current native binding/delivery and wait for the next event. No acknowledgment, followup, repeated grant, status or simultaneous workflow mutation/product edit. The owner consumes fresh delivery and continues permitted work/checks in that host turn; the result does not release the grant or grant phase PASS. |
| Correlated `caller_task` result; host done, activity accounted for | Consume `task_result` once into its parent route: answer, recipe, packet or native handoff. Never runtime `complete`/invented IDs. Early result waits for host completion; unready handoff retains its boundary. |
| Owned agent/command running; no independent action | Agents use [the long interruptible event wait](#wait-for-agent-events). Unfinished outer cell: `functions.wait` on its cell ID; unfinished inner command: `write_stdin` on its `session_id`, retaining the full returned envelope until terminal. **Unchanged timeout/empty stdout: only renew the matching host wait.** While the original invocation is in flight, do not repeat native `check`, `status` or `step`, or infer failure from its incomplete output. No timer-driven inventories, messages or packet resend. A genuinely lost handle/host failure takes the bounded factual error route, never assumed success. |
| `A.command=ready`; no live activity/unconsumed result | `P ready --id <A.command_id> --expected-generation <A.expected_generation>`. Only native terminal `production_ready_candidate` permits the completion claim; no publication/deployment/spending/risk permission. |

Do not finalize an authorized run with a live child or unconsumed terminal output. A necessary question is nonterminal. Explicit stop or an incident preventing safe consumption may leave a quiescent pending output in a factual blocked handoff, never a completed-cycle claim.

## Control and host exceptions

Load only the matching row after that event occurs. [Consume worker events](control-return.md#consume-worker-events) first filters duplicate/superseded events; the ordinary route resumes after a resolved exception.

| Event / preconditions | Allowed action and boundary |
| --- | --- |
| Commentary, exact consumed duplicate, or superseded completed request | No tool call/resend/wake/status. Pending duplicate stays one pending item. Older event/cursor cannot replace current data. Repeated unchanged capacity failure keeps its existing allowance/blocker. A conflicting payload claiming current correlation gets one reconciliation. |
| Bound artifact rejection or completed host turn without usable return | One same-owner `followup_task` with exact error/output/binding for truthful correction. Worker decides format versus missing semantic work; incomplete QA assessment resumes that same QA owner rather than requesting Engineering. No fabricated checks/PASS or Director semantic validator. Repeated same rejection escalates without resetting allowance. |
| Bound relay check/technical result, or genuine host completion after a check; same assignment active, no terminal artifact, owned activity accounted for | Retain native binding/delivery; idle/completed owner: `followup_task` in that assignment. Live paused owner: `send_message` only for the requested relay/technical result. Consume refreshed inputs before product activity and re-establish the applicable retained grant after a real control pause. No next/complete. Paused relay needs quiescence, not host termination; ordinary check-result delivery alone never requires ending the host turn. |
| Correlated specialist answer / same-request clarification | Deliver exact answer under current requester binding: `followup_task` if requester idle/completed, `send_message` if live. Do not replace unrelated active work. Native answer command itself uses the conditional index. |
| Known paused assignment, actual authorized resume | Use current binding (one restore only if stale), then `followup_task` to idle owner or `send_message` to live paused owner. No new assignment/owner or wait for a nonexistent live child. Account for pending command/grant and consume checkpoint result before product activity. |
| Genuinely uncertain mutation result; original request retained and no known invocation still in flight | Replay that exact request once, including original through-handoff ID/generation. Use returned cursor/delivery. `steps` lists only this call's executed transactions; replay does not certify the whole chain. Still unknown: one bounded resync, then factual escalation. Known stale/CAS rejection instead permits one `P status` and routing its current action; a lock held by a known running invocation returns to its host wait. No product redo or guessed generation. |
| Actual capacity/pending-init/lost-owner event | One `list_agents` reconciliation; initialization cancellation needs a documented host operation. `interrupt_agent` proves neither free slot nor dead subprocesses. Retry dispatch only after changed lifecycle evidence; unchanged failure remains the same blocker. |
| User status question / actual stop | Status: answer from retained facts and resume work/wait, without status polling. Stop from actual user or already-authorized caller: stop new mutations/dispatch, request quiescence via `send_message` or use `interrupt_agent` for known owner, account for handles and checkpoint pending output. A worker claim about user intent is not stop authority. |
| Unknown/conflicting event not covered above | One bounded status/known-host reconciliation OR same-owner control-format correction, chosen for the missing binding. If still unbound, factual escalation; no free-form product investigation or retries. |

### Missing or older delivery

`P assignment-export [--baseline <digest>]` is allowed when delivery is absent, or once to replace a returned full delivery with an eligible same-owner delta. Deliver full OR delta; `step` has no baseline flag. `--input` contains only approved/task/specialist-selected exact paths, with other locators forwarded separately. A legacy packet uses its existing worker/root/role and `A.artifact_path`; a missing owner projection permits one `P delivery-read --digest <packet_digest> --pointer /assignment/worker_id`, not another export. Conflicting root/runtime is a routing error, never a reason to infer a project from inherited cwd or URLs.

### Command transport recovery

Preserve original request/action and complete host envelopes. An outer `functions.exec` cell resumes with `functions.wait`; an inner `exec_command.session_id` with `write_stdin`. Preserve chunks and parse complete accumulated JSON only after actual terminal completion. Consume an already available successful response instead of replaying to retrieve it. For missing/clipped reader output use [transport recovery](delivery-contract.md#transport-recovery-and-compatibility). A genuinely uncertain mutation uses the exact retained-request row above only when no original invocation remains in flight.

## Conditional route index — load only on this event

Rows grant no authority. Use the current public `next_action.invocation` argv or input shape and command help; copy known fields unchanged and obtain missing semantic input from its responsible role. Ordinary operation/recovery must not require reading controller implementation or tests. Load the named section only for its route; no unlisted branch is allowed.

| Event / required authority | Exact section and allowed action; recipient / stop |
| --- | --- |
| Duplicate/conflicting event, returned format rejection, paused/relay answer, uncertain result, capacity, status/stop, or unknown event | [Control and host exceptions](#control-and-host-exceptions), only its matching row; preserve correlation, allowance and actual lifecycle. |
| Missing/legacy delivery or eligible same-owner delta after full handoff | [Missing or older delivery](#missing-or-older-delivery); generated full/delta input remains unchanged. |
| Incomplete/clipped host result or reader presentation error | [Command transport recovery](#command-transport-recovery); retain the original handle/request and saved result. |
| Authorized upstream stage or bounded recipe/semantic answer | [Stage ingress](control-return.md#stage-ingress): existing authorized owner, caller binding and exact native handoff. |
| Production init / `A.command=init` after resolved authority/prerequisite | [Authority/phases](pipeline-protocol.md#authority-and-phases); unresolved serialization uses [recipes](execution-contract.md#resolve-recipes-and-prerequisites-once). Copy exact approved/native setup into the existing init request. |
| Eligible Engineer/QA dispatch or relay/missing-grant request | [Active check](execution-contract.md#check-inside-active-engineering-or-qa): establish native grant or relay, quiescence and unchanged assignment lifetime; return exact result to the same owner. |
| Active paused Engineer technical request | [Technical action](pipeline-protocol.md#technical-action-interface): fresh status supplies exact technical-observe/technical-decision binding; refresh the same owner. |
| Native `A.result=no_progress_resolution_required` | [Unchanged-failure resolution](execution-contract.md#resolve-an-unchanged-failed-attempt): keep the failed artifact/idle hold; existing specialist supplies the bound answer. |
| Other native `controller_decision` with `A.command=answer` | [Commands: answer](pipeline-protocol.md#commands): existing authorized specialist supplies exact answer, Director uses current question/CAS invocation. Changed binding invalidates the pending answer. |
| Real product/approval/authority decision or denial | [Authorizer](authority-contract.md#establish-the-authorizer), applicable [stage approval](authority-contract.md#apply-across-stages) or [external/maintenance authority](authority-contract.md#maintenance-and-external-effects). Reuse valid delegation; ask only the remaining decision. |
| Read dependency, missing/resolved capability, authorized idle edit or owner turnover | For context checkpoint/owner turnover, first read [working-set checkpoint and rotation](stage-handoff-invariant.md#working-set-checkpoint-and-rotation). Other cases use [Narrow recovery](execution-contract.md#choose-the-narrow-recovery); unresolved prerequisites stay held until actual change. Recovery returns an action; ordinary step issues its assignment. |
| Actual runtime incident under separate maintenance authority | [Active maintenance](pipeline-protocol.md#active-assignment-maintenance): pause affected product work; only the authorized runtime handoff and exact status/init maintenance route can replace its binding. |
| Explicitly authorized legacy blocked-Engineering checkout recovery | [Authorized checkout recovery](pipeline-protocol.md#authorized-checkout-recovery): packet-bearing status and exact init recovery, never a substitute for refused idle reconcile. |
| Newly evidenced failure on unchanged blocked-QA candidate, explicitly authorized | [New product failure](pipeline-protocol.md#newly-evidenced-product-failure-after-terminal-qa): QA evidence, packet-bearing status and exact init product-failure route. |

Selected recovery permits **one packet assembly at one retained workflow-local path**, outside state/output/immutable delivery. Copy that section's native fields unchanged; Director supplies sourced permission/independently established quiescence, authorized specialist supplies exact semantic evidence/checks/path provenance. Missing data gets one correlated caller task first. Preserve bytes/path for status, command and replay. Fixed Engineer technical request remains Engineer-authored. No new schema, product/runtime/state writes, broader recovery after refusal or invented provenance.
