# Pipeline maintenance observation

Read only for separately authorized pipeline maintenance/observation. Follow the [authority contract](authority-contract.md): a valid prior explicit delegation may cover this incident; product activation alone does not. Pause affected product transitions and establish writer/process quiescence before maintenance. Distinguish run-state reconcile from editing shared runtime sources and name the exact permitted target.

Pipeline-observation workers report every issue observed within their assigned observation scope and verify the evidence before concluding. The pipeline-maintenance observer ledger classifies issues as `pipeline`, `test`, `product`, or `environment`. Review and QA instead stop at their bounded stage contracts: Review reports only findings eligible under its controller-derived `review_target`; QA records only assigned acceptance checks. Observation never creates a general improvement mandate.

Use one compact incident packet: failed public action/category, generation and candidate binding, expected/observed result, relevant redacted stdout/stderr or exact report, changed paths, prior attempts and applicable authorization. Investigate one reproduction, make the smallest root-cause repair within scope, and run focused plus materially affected regressions. Keep the incident writer for related fixes; independent verification checks before/after invariants and absence of fabricated credit. Machine hash/set/diff checks replace repeated state dumps, not semantic verification.

After verified recovery, send one terminal acknowledgment with source state/generation/time, repair evidence, invalidated/preserved credit and exact next action. Refresh required projections through their supported owner route once; a stale projection is not authoritative over current source state. No observer polling or timed transcript requests. If the host cannot reconcile pending slots or a required environment remains unavailable, report that limitation honestly instead of claiming pipeline code repaired it.
