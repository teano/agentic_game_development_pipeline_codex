# QA semantic artifact

The issued `assignment.artifact_schema` and shared [QA acceptance contract](../../gamedev-pipeline/references/qa-acceptance-contract.md) define the terminal result. Follow [Complete terminal results](../../gamedev-pipeline/references/qa-acceptance-contract.md#complete-terminal-results) for every assertion's method, applicability, evidence and reason classification, including pass, fail and blocked. The complete source-bound inventory applies to all outcomes. Prior observations identify work and gaps; they grant no current credit.

For a bound contract, use [Incremental assessment](../../gamedev-pipeline/references/qa-acceptance-contract.md#incremental-assessment) and `qa-finalize`. It derives identity summaries, aggregates and the exact issued terminal output from evaluated rows and retained technical decisions. Keep semantic assessment in the group request; the native helper supplies schema/binding data. Identity `checks[].evidence` is a non-empty string, while assertion `evidence` is an array of concrete records; the normal writer constructs these levels. Direct/legacy construction still follows that exact schema. Finalization validates declared structure, not observation truth or faithful source decomposition.

When `context.qa_contract.status` is `unresolved`, retain available observations and return `blocked` with the precise missing source-grounded contract and required binding action; `checks: []` is permitted at this boundary. The authorized owner binds the contract through `init --qa-contract` at an idle boundary, followed by current-candidate Review. This exception supplies no method equivalence, acceptance change, document regeneration or PASS.

Verdict-changing ambiguity uses the existing nonterminal clarification route. Relevant current journal entries and obstacles use the [event-specific instruction route](../../gamedev-pipeline/references/stage-handoff-invariant.md#event-specific-instruction-route); recorded decisions provide no acceptance or execution authority. Finish under the shared terminal boundary. The issued output right is separate from persistent product write access.
